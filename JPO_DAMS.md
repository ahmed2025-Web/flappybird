# 🎮 Flappy Bird Éducatif - Formation DAMS

## Modifications Effectuées

Ce jeu Flappy Bird a été transformé en un outil éducatif pour les **Journées Portes Ouvertes** de la formation **DAMS** (Data Science, Management et Software Architecture).

### Fonctionnalités Principales

#### 1. **Obstacles Représentant les Difficultés de Formation**
Au lieu de simples tuyaux, les obstacles représentent maintenant les défis rencontrés en DAMS:

- 🟦 Projet Piscine
- 🟦 Projet Web
- 🟦 Projet Data
- 🟦 Algorithmique
- 🟦 Langage C
- 🟦 Swift
- 🟦 Java
- 🟦 Kotlin
- 🟦 R
- 🟦 Machine Learning
- 🟦 Deep Learning
- 🟦 Statistical Learning
- 🟦 Finance
- 🟦 Comptabilité

#### 2. **Quiz Interactif par Obstacle**
À chaque collision avec un obstacle, un quiz s'affiche avec:
- **La difficulté** affichée en haut (ex: "Projet Piscine")
- **Une question spécifique** à cette difficulté
- **3 réponses possibles** (1 bonne, 2 mauvaises)
- **Feedback immédiat** (vert pour bonne réponse, rouge pour mauvaise)

#### 3. **Gameplay Éducatif**
- **Bonne réponse**: Le jeu continue, l'oiseau reprend son vol
- **Mauvaise réponse**: Game Over, fin de la partie
- **Score**: Augmente à chaque tuyau dépassé
- **Progression**: Les obstacles s'affichent dans l'ordre des difficultés


### 🎮 Comment Jouer

1. **Lancer le jeu**: `make run
2. **Éviter les obstacles**: Cliquer ou appuyer sur Espace pour sauter
3. **Répondre aux quiz**: Cliquer sur la bonne réponse
4. **Continuer ou échouer**: 
   - ✓ Bonne réponse → Continuer le jeu
   - ✗ Mauvaise réponse → Game Over
